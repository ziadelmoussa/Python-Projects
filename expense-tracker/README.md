# Expense Tracker

A simple Python CLI expense tracking application that allows users to record, view, analyze, and delete expenses using JSON file storage.

## Features

* Add expenses
* View all recorded expenses
* Delete expenses
* Calculate total spending
* View spending by category
* Persistent data storage using JSON
* Input validation and error handling

## Expense Information

Each expense stores:

* Amount
* Category
* Description

## How to Run

Run the following command in the terminal:

python main.py

## Files

* `main.py` → Main application logic
* `expenses.json` → Stores all recorded expenses
* `.gitignore` → Ignores unnecessary Python cache files
