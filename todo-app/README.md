# To-Do List App

A simple Python CLI to-do list application that allows users to manage and track tasks using JSON file storage.

## Features
- Add tasks
- View tasks
- Mark tasks as complete
- Delete tasks
- Persistent task saving using JSON
- Task status tracking
- Automatic file loading and saving

## How to Run

Run the following command in the terminal:

python main.py

## Files
- `main.py` → Main application logic
- `tasks.json` → Stores saved tasks
- `.gitignore` → Ignores unnecessary Python cache files
