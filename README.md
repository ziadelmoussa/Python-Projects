# Calculator

A simple Python CLI calculator that allows users to perform basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division by zero protection
- Continuous calculator loop until exit

## How to Run

Run the following command in the terminal:

python main.py
