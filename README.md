# Contact Book App

A simple Python CLI contact book application that allows users to store, manage, update, and delete contacts using JSON file storage.

## Features
- Add contacts
- View all contacts
- Search contacts
- Update contact information
- Delete contacts
- Email validation using regex
- Persistent contact saving with JSON
- Input validation
- Back navigation using '<'

## Contact Information
Each contact stores:
- Name
- Phone number
- Email address

## How to Run

Run the following command in the terminal:

python main.py

## Files
- `main.py` → Main application logic
- `contacts.json` → Stores saved contacts
- `.gitignore` → Ignores unnecessary Python cache files
