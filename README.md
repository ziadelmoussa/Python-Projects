# Quiz App

A simple Python CLI quiz application where users can choose quiz categories and answer multiple-choice questions.

## Features
- Multiple quiz categories
- Multiple-choice questions
- Score tracking
- Percentage calculation
- Replay option
- Input validation

## Categories
- Science
- Math
- Geography

## How to Run

Run the following command in the terminal:

python main.py
